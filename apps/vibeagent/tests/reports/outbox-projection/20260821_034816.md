## Reproducibility and limits

The test uses a unique transaction prefix, so its SQL cleanup is limited to rows whose transaction key equals that prefix. It proves the committed outbox path and projection advance on the deployed stack. It does not simulate a live PGMQ outage; the bounded retry/DLQ transition remains covered by the deterministic store test and controlled SQL-state verification.
