# --- notebooks ---------------------------------------------------------------
# A kernel that outlives one command.
#
# Running Python as a series of one-shot scripts throws away every variable
# between them, so anything exploratory has to re-derive its own state — reload
# the file, re-fit the model, re-parse the document — on each step. A kernel
# keeps it, which turns "run this script" into "keep working in the same
# session", and nbconvert makes the result something a person can be handed.
ipykernel
jupyter-client
nbclient
nbconvert
nbformat
jupyterlab
