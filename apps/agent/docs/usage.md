# Usage

Run `npm run build --workspace agent`, then start the Compose stack. Send `echo` or `hash.sha256` actions to `/api/events`. Set `DATABASE_URL`, queue names, and queue tuning variables through `apps/agent/docker/.env`, which is materialized from `docker/env.defaults` by the deploy script.

The deploy script materializes `.env` only when it is absent, so an existing deployment does not pick up new keys. To enable `GET /metrics` on a stack that already has a `.env`, append `AGENT_METRICS_TOKEN=<token>` to it and redeploy; leaving it unset keeps the endpoint disabled. Unless overridden, `AGENT_MAX_THREADS` and `AGENT_MIN_THREADS` are both twice the detected CPU count: the pool creates that fixed resident CPU-bound capacity at startup. Set both only as an explicit pair when the container CPU limit differs. The durable transaction pool defaults to half that worker count, capped at 48, while PGMQ readers and writers use isolated pools. `/metrics` reports each pool's `total`, `idle`, and `waiting` connections under its durable, ingress-reader, and queue-writer prefix, plus `workerPoolWorkers`, `workerPoolBusy`, and `workerPoolQueued`; investigate sustained waiting or queued work before increasing worker count. Outbox delivery is independently leased by `AGENT_OUTBOX_LEASE_SECONDS` (default 30), dispatched by `AGENT_OUTBOX_DISPATCHERS`, and uses `AGENT_OUTBOX_MAX_ATTEMPTS` plus `AGENT_OUTBOX_RETRY_BASE_MS` for capped retry and DLQ transition. `AGENT_SHUTDOWN_GRACE_MS` (default 30,000) bounds orderly drain after SIGTERM/SIGINT; interrupted leased work is reclaimed on restart. WebSocket replay pages at `AGENT_WEBSOCKET_REPLAY_MAX` rows (default 256); a client must resubscribe with the `replay` frame cursor until `replayComplete` is true.
