# Internals

`src/server/queue/transport.ts` owns the broker-neutral delivery contract. `src/server/pgmq` owns PGMQ SQL calls and implements that contract. `src/server/database.ts` constructs the separately injected Postgres pool.

`src/server/event-store` owns immutable canonical envelopes: it serializes equal event IDs with a transaction advisory lock, returns an existing row without reserving another sequence, and assigns a per-stream sequence only to a new row. `sequence` is `bigint`, which `pg` returns as text, so the store converts it before it reaches an envelope; nothing downstream may compare a raw row value. `ensureSchema` also backfills `session_id`, `run_id`, and `turn_id` on rows written before those columns existed, using the legacy payload keys and the `session:` stream prefix.

`src/server/ingress` converts the deployed queue contract into that canonical draft. A result carries no session payload, so `toResultDraft` derives it from the persisted request envelope: stream, session, run, turn, and correlation are inherited and `causationEventId` points at the request. Results therefore stay in the requesting session's stream instead of collecting in one global channel stream.

The consumer awaits the append before any PGMQ delete. Result identity is derived — `result:<transactionKey>` and `conflict:<eventId>` hashed into a stable UUID — so a redelivered request converges on one stored result and one client-visible event ID rather than appending a new row per delivery. `src/server/consumer.ts` owns the single async read/process loop, bounded reconnect backoff, CPS-style result transition, and periodic message-visibility extension while one message runs. `src/server/execution` stores the transaction-key claim. `src/server/metrics` holds the aggregate counters behind `GET /metrics`. `src/server/worker` owns a lazy bounded Worker Thread pool and the worker action allow-list; no worker is created for an empty queue.

`agent_events` is frozen. The consumer no longer writes it, `event_store` is the only append target, and the table is kept read-only for rows written before the canonical store existed. Phase 7 of the [Agent Renewal plan](../../../agentRenewal.md) drops it.
