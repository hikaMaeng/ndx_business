# Internals

`src/server/queue/transport.ts` owns the broker-neutral delivery contract. `src/server/pgmq` owns PGMQ SQL calls and implements that contract. `src/server/database.ts` constructs the separately injected Postgres pool.

`src/server/event-store` owns immutable canonical envelopes: it serializes equal event IDs with a transaction advisory lock, returns an existing row without reserving another sequence, and assigns a per-stream sequence only to a new row. `sequence` is a `bigint` exported as an exact decimal string, never a lossy JavaScript number. `ensureSchema` backfills `session_id`, `run_id`, and `turn_id` using legacy payload keys and the `session:` stream prefix, then raises every stream counter to the stored maximum.

`src/server/ingress` converts the deployed queue contract into that canonical draft. A result carries no session payload, so `toResultDraft` derives it from the persisted request envelope: stream, session, run, turn, and correlation are inherited and `causationEventId` points at the request. Results therefore stay in the requesting session's stream instead of collecting in one global channel stream.

`startIngressConsumer` starts `AGENT_INGRESS_CONSUMERS` independent durable-handoff lanes. Each awaits canonical append and `event_processing_job` insertion before PGMQ delete, then immediately returns to ingress; it never awaits a worker. Long-poll readers own a dedicated pool, queue writers own another, and the durable event/execution/lease pool is separately bounded by `AGENT_DATABASE_POOL_MAX`; a parked PGMQ read must never starve durable commits. `startScheduler` is the sole worker dispatcher: it starts exactly `AGENT_MAX_THREADS` durable-job claim lanes, matching the bounded worker-pool capacity. Each lane atomically claims a job, renews its lease while the worker runs, and marks it complete only after result delivery. Scheduler errors return the job to retry rather than killing the lane. Result identity is derived — `result:<transactionKey>` and `conflict:<eventId>` hashed into a stable UUID. `src/server/delivery` claims each result with a durable lease of `AGENT_DELIVERY_LEASE_SECONDS` and marks it delivered only after queue and hub publication. The claim is three-valued: `delivered` lets a source redelivery be acknowledged without sending again, `leased` means another attempt is still running and raises rather than acknowledging, and only `claimed` sends. Worker completion is recorded before this egress attempt, and egress errors never rewrite that terminal execution state. `src/server/execution` stores the transaction-key claim. `src/server/metrics` holds aggregate counters plus ingress active handoffs, scheduler backlog age, expired lease count, and active dispatches behind `GET /metrics`; it never exposes payloads or identifiers. `src/server/worker` owns a lazy bounded Worker Thread pool and the worker action allow-list; no worker is created for an empty queue.

`agent_events` is frozen. The consumer no longer writes it, `event_store` is the only append target, and the table is kept read-only for rows written before the canonical store existed. Phase 7 of the [Agent Renewal plan](../../../agentRenewal.md) drops it.
