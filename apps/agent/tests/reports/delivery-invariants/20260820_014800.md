## Failures
None against the plan.

Goals 1–4 are proven by unit tests rather than against the deployed stack: inducing a durable-state
outage or a live delivery lease on the running database would corrupt shared state. The prior
behaviour was reproduced against the previous build before the fix — a `completeExecution` failure
left `extendVisibility` running (3 calls at stop, 6 three seconds later) with the message never
acknowledged, and a held lease produced `{"resultQueueSends":[],"sourceAcknowledged":["m1"]}`.
Both are now regression tests in `apps/agent/src/server/consumer.test.ts`.

run; row counts, delivery state, counter consistency, and the queue delta do not.
`docker exec admin psql -U postgres -d ndx_business` reaches the database.
