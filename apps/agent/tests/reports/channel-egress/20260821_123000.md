# Slow-consumer isolation report

## Scenario

Two WebSocket clients subscribed to `slow.test`. The first paused its TCP socket after subscription; the second continued consuming frames. Sixteen HTTP commands with 180 KiB payloads were submitted to the shared channel.

## Result

| Check | Observed |
| --- | --- |
| Normal subscriber | received all 16 canonical command events |
| Paused subscriber | remained isolated; it did not block the normal subscriber |
| Agent container | `running/healthy` after the burst |

The local loopback socket did not reach the 1 MiB kernel-buffer disconnect threshold in this 2.88 MiB application burst, so this run proves isolation rather than the close threshold. The mailbox unit test covers the deterministic terminal-overflow close rule. All 16 transaction rows and exact result-queue messages for `slow-live-1787249472542` were removed after observation.
