# Canonical channel live-routing report

## Environment

The deployed `agent` container was `running/healthy`; `/health` returned 200.

## Scenario

Opened two WebSocket clients, subscribed one to `agent.results` and the other to `orders`, then submitted one `hash.sha256` command with reply channel `agent.results`.

## Result

| Subscriber | Received canonical result channels |
| --- | --- |
| `agent.results` | `agent.results` |
| `orders` | none |

This proves channel filtering is performed by the canonical live router. The generated command/result transaction is ordinary durable test data and is not used as queue-drain evidence.
