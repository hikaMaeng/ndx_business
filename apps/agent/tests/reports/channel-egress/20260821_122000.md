# Broad multi-stream cursor replay report

Subscribed to `agent.results`, whose existing history spans more than the former in-token stream cap, and retained the server-issued UUID cursor. After disconnecting, submitted one `hash.sha256` result to `agent.results`, then reconnected with that cursor.

The reconnect received the offline transaction exactly once. The cursor token remained a fixed UUID; its channel fingerprint and multi-stream positions were held in `event_subscription_cursor`. The transaction's exact event, processing, execution, delivery, and PGMQ rows were deleted after the run. The disposable cursor row was also removed.
